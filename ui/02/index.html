About the Service & Technology

Q: What is the main purpose of this service?
While this tool excels at creating concise summaries, its primary goal is to build a personal map of content consumption. By visualizing every video watched, users can reclaim control from recommendation algorithms.
Q: Who pays for this?
Built primarily for personal use. To keep it free for others, I utilize Google’s free developer tier (currently ~20 requests/day).

Map Status (Oct 2025)

The current map is a manually generated UMAP plot of the first 4,000 entries. Now that the database has reached 8,000 entries, a regeneration is planned.
