FAQ & Tech Specs
What is the main purpose of this service?

While this tool excels at creating concise summaries, its primary goal is to build a personal map of content consumption. By visualizing every video watched, users can reclaim control from recommendation algorithms and discover related content organically via the "local neighborhood" of topics.

How does the Map work?

The map uses UMAP (Uniform Manifold Approximation and Projection) to plot videos based on semantic similarity. Similar videos cluster together. The current map background represents a database of over 8,000 processed entries.

Why do I get a "Transcript too short" error?

This usually happens due to: 1. YouTube blocking automated downloads. 2. No captions available. 3. Language incompatibility.
Workaround: Manually copy the transcript from YouTube and paste it into the text tool.

Who pays for this?

I built this for personal use. It runs on Google’s free developer tier (currently 20 Flash requests/day shared among all visitors).

How does the AI "watch" the video?

It downloads the text transcript via yt-dlp. The text is processed by an LLM (Gemini). It does not process the video pixels directly, only the spoken words.
